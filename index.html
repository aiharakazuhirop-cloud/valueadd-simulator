Value-Add Return Simulator　

Value-Add Return Simulator

オフィス・住宅・複合のバリューアド案件を、取得・改修・リースアップ・売却まで月次で追い、税引後に手元へ残る利益まで計算します。金額は万円単位。

最終収益と取得時・出口時の比較

上段は投じた資金・戻った資金・税金の差し引き。下段は資本構成と主要指標の比較（出口時は売却年の値、NOIは売却価格の算定に使う翌年NOI）。

賃料表

区画タイプ別の専有面積・坪単価から算出した満室想定賃料（共益費込み・初年度水準、フリーレント控除前）。

売却時の収支

売却価格から費用・譲渡税・借入完済を差し引き、手元に残る金額。

エクイティ累積キャッシュフロー（Jカーブ・税引後）

取得と改修で投資額が最も深くなり、運営収入と売却で回収されるまでの推移。

判定

前提のどこにリターンが依存しているかを示します。

    価値創造ブリッジ

    総事業費に対し、安定稼働後のNOIを出口時の利回りで評価した価値（賃料上昇を除く）。

    月次NOIと稼働率の推移

    帯は事業フェーズ（赤の濃い帯は工期延長）。棒が月次NOI、線が稼働率。

    感度分析：税引後IRR

    年次キャッシュフロー

    万円。売却年のエクイティCFには売却手取りを含みます。

    年次モデルの簡易試算です。内部は月次で計算し、表は年次に集計しています。改修費は予定工期で均等に支出し（工期延長の追加費用は延長月で按分）、改修済み区画の割合は竣工月まで直線的に増えて賃料に反映、竣工後は用途ごとのリースアップ期間で安定稼働率へ直線的に回復すると仮定しています。フリーレントは、リースアップで新たに埋まる面積に改修後賃料×フリーレント月数を掛け、リースアップ期間に均等に計上しています。税金は、課税所得＝NOI−支払利息−減価償却（定額法、取得諸費用は取得価額に算入）、損失は以後の年に繰り越して計算します。法人は譲渡益を売却年の所得に合算し、個人は譲渡所得を分離課税（長期20.315%・短期39.63%、保有期間6年以上を長期と判定）としています。消費税・登録免許税・不動産取得税の区分、個人の損益通算、特例は考慮していません。実際の申告は税理士にご確認ください。
