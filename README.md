# Value-Add Return Simulator

オフィス・住宅・複合ビルのバリューアド（改修による価値向上）投資について、取得から改修、リースアップ、売却までを月次で計算し、税引後に手元に残る利益まで試算するブラウザツールです。

インストールは不要です。`index.html` をブラウザで開くか、GitHub Pages の URL にアクセスすれば使えます。

## できること

- 延床面積・階数から区画構成と満室想定賃料を自動作成（坪・㎡を併記）
  - 専有面積は「自動」（延床面積 × 想定レンタブル比 ÷ 総階数。初期値はオフィス75%・住宅80%・複合75%）と「詳細」（1階・基準階・地下を個別に入力）を切り替え可能
- 物件名を入力でき、画面と印刷の先頭に表示（印刷日も表示）
- 物件タイプの切り替え：オフィス／住宅／住宅・オフィス複合（オフィス比率を指定）
- 地下階の設定：地下階数・地下の用途（店舗／オフィス／賃貸なし）・1階あたりの地下専有面積を入力し、地下の坪単価は地上の同じ用途の単価に地上比（%）を掛けて算出
- 用途ごとの安定稼働率・リースアップ期間・フリーレント
- 運営費を内訳で入力：Opex（PM・BM・水道光熱費と同収入・修繕費・公租公課・保険・リーシング費用・その他）、Capex（延床・収入比）、ファンド費用（AM取得・期中・売却報酬、SPC運営費）。年次キャッシュフロー表で NOI・NCF・投資家の手取りまで追える
- 売却価格はキャップレートを NOI か NCF に掛けて算出（キャップレート・BM費・AM報酬の目安を表示）
- 予定工期と工期延長を月単位で設定し、延長による利回りへの影響を確認
- 売却価格はキャップレートから算出するか、金額を直接指定
- 法人／個人の課税（減価償却、譲渡益課税、長期・短期譲渡の判定）
- 税引後IRR、エクイティ倍率、Jカーブ、感度分析、年次キャッシュフロー表

## 使い方

1. 左パネルに前提条件を入力します。金額は万円単位、坪単価は共益費込みの月額（円/坪）です。
2. 右側の主要指標・最終収益・グラフが入力に合わせて即座に更新されます。
3. 入力内容（物件名を含む）は各自のブラウザに自動保存されます。他の人と共有されることはありません。「初期値に戻す」で初期状態に戻ります。

## 前提と注意

- 年次の簡易モデルではなく内部は月次計算ですが、投資判断のための概算ツールです。
- 運営費と出口キャップレートは物件全体で1つの値です。複合用途の精緻な評価には用途別の設定が必要です。
- 消費税、不動産取得税、登録免許税、個人の損益通算や特例は考慮していません。
- リーシング費用はリースアップ中の新規契約だけを計上します（安定期のテナント入替、AMの成功報酬は扱っていません）。
- 実際の税務・融資条件は、税理士・金融機関に確認してください。

## 既存の保存データへの影響（運営費の内訳化）

以前の版で入力・保存したデータは、初回の読み込み時に自動で新しい形式に移し替えます。

- 旧「運営費」は「その他運営費」に、旧「修繕積立（収入比）」は「Capex（収入比）」に移ります。ほかの新しい費用項目は0、売却価格はこれまでどおり NOI 基準で、キャップレートも保存値のままです。
- 税引前IRR・売却価格は変わりません。
- 税引後IRRは約 +0.1pt 上がります（例：初期値 14.11% → 14.23%）。これまで税計算に反映されていなかった修繕積立（Capex）を、資産に計上して減価償却するよう修正したためです。
- DSCR は NOI 基準から NCF 基準（Capex 控除後）に変わり、低めに出ます（例：初期値の安定期最低DSCR 1.87 → 1.80）。
- 以前の保存データは消さずに残しているため、旧版に戻した場合も元の入力が使えます。

## テスト

計算部分の検算テストは Node.js（18以上）の標準機能だけで動きます。リポジトリ直下で次を実行します。

```
node --test
```

## 動作環境

最新版の Chrome / Edge / Safari / Firefox。インターネット接続時は Google Fonts を読み込みます（オフラインでも代替フォントで動作します）。

## 更新方法

`index.html` を新しい版に差し替えてコミットすると、GitHub Pages にも数分で反映されます。
