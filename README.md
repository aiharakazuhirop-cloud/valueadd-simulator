# Value-Add Return Simulator

オフィス・住宅・複合ビルのバリューアド（改修による価値向上）投資について、取得から改修、リースアップ、売却までを月次で計算し、税引後に手元に残る利益まで試算するブラウザツールです。

インストールは不要です。`index.html` をブラウザで開くか、GitHub Pages の URL にアクセスすれば使えます。

## できること

- 延床面積・地上階数・基準階専有面積から区画構成と満室想定賃料を自動作成（坪・㎡を併記）
- 物件タイプの切り替え：オフィス／住宅／住宅・オフィス複合（オフィス比率を指定）
- 地下階の設定：地下階数・地下の用途（店舗／オフィス／賃貸なし）・1階あたりの地下専有面積を入力し、地下の坪単価は地上の同じ用途の単価に地上比（%）を掛けて算出
- 用途ごとの安定稼働率・リースアップ期間・フリーレント
- 予定工期と工期延長を月単位で設定し、延長による利回りへの影響を確認
- 売却価格はキャップレートから算出するか、金額を直接指定
- 法人／個人の課税（減価償却、譲渡益課税、長期・短期譲渡の判定）
- 税引後IRR、エクイティ倍率、Jカーブ、感度分析、年次キャッシュフロー表

## 使い方

1. 左パネルに前提条件を入力します。金額は万円単位、坪単価は共益費込みの月額（円/坪）です。
2. 右側の主要指標・最終収益・グラフが入力に合わせて即座に更新されます。
3. 入力内容は各自のブラウザに自動保存されます。他の人と共有されることはありません。「初期値に戻す」で初期状態に戻ります。

## 前提と注意

- 年次の簡易モデルではなく内部は月次計算ですが、投資判断のための概算ツールです。
- 運営費と出口キャップレートは物件全体で1つの値です。複合用途の精緻な評価には用途別の設定が必要です。
- 消費税、不動産取得税、登録免許税、個人の損益通算や特例は考慮していません。
- 実際の税務・融資条件は、税理士・金融機関に確認してください。

## 動作環境

最新版の Chrome / Edge / Safari / Firefox。インターネット接続時は Google Fonts を読み込みます（オフラインでも代替フォントで動作します）。

## 更新方法

`index.html` を新しい版に差し替えてコミットすると、GitHub Pages にも数分で反映されます。
